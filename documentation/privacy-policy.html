Privacy Policy

D365 Company & Environment Switcher

Owner: Ahmed Imam
Effective date: 24 November 2026
Version: 1.0

The extension does not collect, transmit, sell, rent, disclose, or share personal information or browsing history.

Information processed locally

The extension processes the active tab URL only after the user opens or uses the extension. It does so solely to detect a Microsoft Dynamics 365 Finance & Operations environment, detect the cmp legal-entity parameter, and navigate the active tab to a user-selected environment or company.

Environment names and URLs, company codes and descriptions, and extension preferences are stored locally using browser extension storage. Exported configuration files are created only when the user selects Export. Imported configuration is read only after the user selects a local JSON file.

No external transmission

The extension contains no analytics, advertising, tracking, telemetry, remote code, external API calls, developer-operated server, or third-party data-sharing mechanism. Configuration and active-tab information are not sent to Ahmed Imam or to any third party by the extension.

Browser synchronization

The release uses local extension storage rather than synchronized storage. Browser vendors may process extension installation and store-account information under their own privacy policies; that processing is outside this extension.

Permissions

  • activeTab: read and update the active tab only when the user invokes the extension.
  • storage: save user-created companies and environments locally.

Retention and deletion

Configuration remains in local browser storage until the user removes items, restores defaults, clears extension data, or uninstalls the extension.

Changes

Material changes to data practices will be disclosed by updating this policy and the store listing before the changed version is released.

Contact the owner through the support contact shown on the extension's official marketplace listing.
