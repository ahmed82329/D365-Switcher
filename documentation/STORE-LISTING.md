## Name
D365 Company & Environment Switcher

## Short description
Switch user-configured Dynamics 365 Finance & Operations companies and environments without manually editing URLs.

## Detailed description
D365 Company & Environment Switcher reduces repetitive URL editing for authorized Microsoft Dynamics 365 Finance & Operations users. Configure your environments and company/legal-entity codes once, then use the toolbar popup to detect the current context and switch immediately.

Features:
- Detect the current environment and `cmp` company value.
- Switch company while preserving the current D365 page and other URL parameters.
- Switch environment while preserving the D365 path, query, and fragment.
- Add, edit, remove, import, export, and restore configuration.
- Keep all configuration in local browser extension storage.
- No analytics, ads, telemetry, tracking, remote code, or external API calls.

Permissions:
- `activeTab` reads and updates the current tab only after the user invokes the extension.
- `storage` saves the user's configuration locally.

The extension does not grant access to D365 and does not bypass authentication or authorization. Independent software; not affiliated with or endorsed by Microsoft Corporation.
