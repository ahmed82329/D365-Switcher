# Publishing Costs — verified 24 November 2026

| Store / browser | Required platform fee | Notes |
|---|---:|---|
| Chrome Web Store | US$5 one-time developer registration fee | Google officially confirms a one-time registration fee; the current published amount is US$5. No annual or per-extension listing fee is identified. Currency conversion, tax, or card charges may apply. |
| Microsoft Edge Add-ons | Free | Microsoft states there is no registration fee for the Microsoft Edge program. |
| Mozilla Add-ons (Firefox) | Free | Mozilla's official submission flow requires a Mozilla account, review, and signing but identifies no developer registration or submission fee. |
| Zen Browser | No separate fee | Zen installs extensions from Mozilla Add-ons, so the Mozilla submission/signing route covers Zen. |

**Minimum mandatory store-platform cost to publish in all three marketplaces: US$5 total.**

Possible non-store costs are optional or external: a domain/hosting plan for the privacy-policy URL, legal advice, trademark filing, copyright deposit/registration, design work, and currency/card charges. A free static host can make privacy-policy hosting cost US$0. Store approval is not guaranteed by payment or submission.
