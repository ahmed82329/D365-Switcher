# Security Policy

D365 Company & Environment Switcher is maintained in the [D365-Switcher repository](https://github.com/ahmed82329/D365-Switcher).

## Supported Versions

| Version | Supported |
| --- | --- |
| 4.0.x | :white_check_mark: |
| < 4.0 | :x: |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests. Submit a private report through the **Report a vulnerability** option on the repository’s [Security tab](https://github.com/ahmed82329/D365-Switcher/security).

Include the affected version, steps to reproduce, impact, and relevant environment details. Remove credentials, tokens, personal information, and other sensitive data from any logs or attachments.

I aim to acknowledge reports within 5 business days and provide updates at least every 10 business days while investigating. If a report is confirmed, I’ll coordinate remediation and disclosure. If it is not accepted, I’ll explain the reason where possible. Please allow time to investigate and coordinate a fix before publicly disclosing a vulnerability.
